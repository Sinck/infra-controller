## [v2.3.0] - 2026-10-01

### Added

- Install Rack Management Service during prerequisite setup, including its database, credentials, and mTLS configuration. Setup now requires RMS image configuration unless RMS provisioning is explicitly skipped. ([#5475](https://github.com/NVIDIA/infra-controller/pull/5475))

Correct ordinary VPC responses to allow 24-bit active VNIs and 1–64-character profile names; uncertain mutation outcomes require an authoritative read before another request. See [https://nvidia.github.io/infra-controller/](https://nvidia.github.io/infra-controller/) for the updated schema. ([#6058](https://github.com/NVIDIA/infra-controller/pull/6058))
- Allow simple-SDK Instance queries across VPCs by opting out of the client's default VPC filter. Unkeyed InstanceFilter literals require an additional field. ([#6656](https://github.com/NVIDIA/infra-controller/pull/6656))
- Allow exact REST VPC Prefix CIDR selection through `prefix` as an alternative to `prefixLength`, requiring exactly one non-null selector and validating alignment, family, containment, SLAAC limits, and conflicts. See [https://nvidia.github.io/infra-controller/](https://nvidia.github.io/infra-controller/) for the updated schema. ([#6867](https://github.com/NVIDIA/infra-controller/pull/6867))
